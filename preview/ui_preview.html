导航状态机

点 CPU 卡 → CPU 详情；点 GPU 卡 → GPU 设备列表（只有 1 个适配器时直进详情）； 点 DISK 卡 → 磁盘详情。
详情页左上 ‹ HOME 返回面板；GPU 详情右上另有 ‹ DEVICES 回设备列表。 设备列表里点任意卡片会同时把它设为面板适配器并进入详情页 —— 一次点击两个效果。

保持的固件规则

· 传感器缺失显示占位符（勾选"隐藏传感器"看 -- 路径）
· GPU 身份只用 protocol id，不用数组下标
· 面板 GPU 数值/条形/折线同取"最忙引擎"
· 60 点历史窗口，断点不插值，切适配器清空
· 文本走 1 Hz 采样节奏，条形 20 Hz 缓动
· 温度 ≥85 °C 转告警色

主机连接页

手机没有 USB 配对通道，所以这一页就是配网流程本身：广播 discovery.probe → 收 discovery.offer → 发 pairing.request → 等 PC 上点确认 → 拿 pairing.grant 的 32 字节密钥 → 开 ws://…:8765/ws 做 challenge/authenticate。
点主机卡：已配对直接进入 online，未配对进入 requesting（PC 上弹窗等确认）。 雷达光点的方位/距离由 hostId 哈希决定，重绘不会乱跳。
